# 六数据集门控实验与冻结投影消融（2026-10-22）

本轮在已完成的 OxfordPets、DTD 基础上新增 Caltech101、Flowers102、EuroSAT 和
FGVCAircraft，组成六数据集主比较。全部主实验使用 ViT-B/16、16 shots、N_CTX=2、
PROMPT_DEPTH=9、5 epochs、原 MaPLe SGD 配方和 fp16，三个配对种子为 1/2/3。
每个数据集的三种模式复用同一固定划分与 few-shot cache；同一 epoch-5 checkpoint 分别
评估 Base 与 Novel。HM 先按种子计算，再报告三个种子的均值与样本标准差。

结果不支持静态通道门控的普遍提升。Channel 在 OxfordPets 和 EuroSAT 的平均 HM 为正，
在 DTD、Caltech101、Flowers102 为负，并在 FGVCAircraft 上出现大幅下降和强种子波动。
Scalar 在 DTD 和 EuroSAT 的平均方向为正，但其余三个新增数据集为负；DTD 的配对差值样本
标准差为 2.2992，不能将均值提升写成稳定收益。

FGVCAircraft 的退化集中在 channel seed 2/3：对应 HM 为 19.6508 和 17.2850，而 seed 1
为 36.0202。三个 seed 的最大 gate 偏离 1 仅分别为 0.00360、0.00125 和 0.00230，均没有
接近 `tanh` 饱和。由此不能把失败简单归因为门控幅度过大；更合理的解释是假设为微小重参数化
改变了低数据、细粒度任务的优化轨迹。该因果机制已由后续三组预登记诊断实验验证：固定恒等
门控对照确认前向实现无 bug，门控学习率消融显示非单调敏感，逐 epoch 轨迹显示崩溃时门控
仍接近恒等映射，详见 [机制诊断结果](DIAGNOSTIC_RESULTS_2026-10-22.md)。

## 冻结深层投影消融

该对照冻结 8 个深层文本→视觉线性投影，浅层投影、文本提示和门控仍可训练。每次训练记录
投影初始/最终摘要；同一种子三种模式从相同投影初始化开始，全部投影在训练后逐张量不变。
该条件改变了原训练问题，只能在消融内部比较。

| 数据集 | 模式 | Base (%) | Novel (%) | HM (%) | 相对冻结 none ΔHM |
|---|---|---:|---:|---:|---:|
| OxfordPets | none | 95.4811 | 97.5205 | 96.4897 ± 0.0964 | — |
| OxfordPets | scalar | 95.6583 | 97.6696 | 96.6525 ± 0.3014 | +0.1628 |
| OxfordPets | channel | 95.6052 | 96.0104 | 95.7952 ± 1.4662 | -0.6945 |
| DTD | none | 79.2824 | 56.5620 | 65.9623 ± 1.8464 | — |
| DTD | scalar | 79.3981 | 58.2528 | 67.1684 ± 1.6560 | +1.2062 |
| DTD | channel | 79.2824 | 57.2061 | 66.4495 ± 0.6771 | +0.4873 |

冻结投影后 channel 仍可能改变结果，说明“投影可吸收 gate”的代数冗余不能直接推出有限步优化
轨迹完全相同。但 OxfordPets channel 的负均值和较大方差也表明，这一重参数化不是稳定增益来源。

## 原始实现重放与验收

固定官方 `trainers/maple.py` fixture 的 SHA-256 后，在当前环境对 DTD none 做三个种子的完整
训练与 Base/Novel 评估。三个新 checkpoint 与此前 none checkpoint 的全部状态张量逐元素相同，
每个种子的 `unequal_tensor_count` 均为 0；这确认当前 `none` 路径没有因门控代码产生行为变化。

最终验收实际加载并检查 57 个新增正式训练 checkpoint：新增四数据集主实验 36 个、冻结投影
18 个、DTD 上游重放 3 个。验收结果为 `EXPANSION_VERIFIED 57`，并确认：

- 所有 checkpoint 为 epoch 5，全部浮点张量有限；
- 冻结 CLIP 张量与既有 OxfordPets none 参考逐元素一致；
- 四个新增数据集的 fixed split 与三个 few-shot cache 摘要在训练后不变；
- scalar/channel 均含 8 个门控参数组，形状分别为标量和 768 维，均发生非零学习变化；
- 冻结投影 checkpoint 有独立 schema，投影训练前后不变；
- 当前远端环境重新运行 21 项测试，1.655 秒全部通过。

检查的是发布仓结构，不是模型训练；失败日志已保留，没有通过补造文件来伪装通过。发布仓在
提交前应单独运行其仓库结构检查。
