## 暂定题目

- 中文：**MaPLe 复现与再分析：跨模态门控为何无效，以及教师可信度加权的知识一致性**
- 英文：*Revisiting MaPLe: Why Cross-Modal Gating Stays Idle and Reliability-Weighted Knowledge Consistency*

## 摘要（约 200 字，最后写）

1. 背景：MaPLe 逐层把文本 prompt 线性投影为视觉 prompt；训练后新类精度在部分数据集上反而低于零样本 CLIP。
2. 门控分析：在深层投影后加静态门控（可被吸收进投影、不扩表达）与输入条件门控（不可吸收），六数据集 × 三种子
   显示均无稳定提升；门控统计表明两者训练后都仅偏离恒等 1e-4~1e-3，原配方下几乎未被训练。
3. 稳定性：Aircraft 五种子显示原版 MaPLe 本身就会崩溃（1/5），静态门控 3/5，梯度裁剪不能消除。
4. 方法与结果：零样本一致性约束按冻结 CLIP 对训练样本真实类别的概率加权；六数据集平均 HM 76.59→76.95，
   Base/Novel 同时提升，DTD +5.86；但 EuroSAT 仍 −4.55，Pets/Caltech 小幅下降。

## 1 引言（约 1 页）

1. CLIP 零样本 → prompt learning（CoOp、CoCoOp、VPT）→ MaPLe 的深层跨模态投影。
2. **两个观察**（用本项目数据）：
   - 新类遗忘：DTD 零样本 Novel 60.27 > MaPLe 55.88；Flowers 77.52 > 73.43。
   - 不稳定：Aircraft 原版五种子中一个 HM 跌到 19.44。
3. 我们先尝试"门控"这一直觉改进，并系统分析其为何无效；再针对遗忘提出可信度加权的一致性约束。
4. 贡献：
   - 静态门控的可吸收性分析 + 六数据集负结果 + 预登记诊断；输入条件门控对照 + 门控统计，
     揭示两类门控在原配方下都"闲置"（偏离恒等 ≤1e-3）；
   - 五种子稳定性实验：崩溃属于 MaPLe 原配方，梯度裁剪无效，修正了"门控导致崩溃"的初步判断；
   - 教师可信度加权 KC：只用训练标签，六数据集平均 Base/Novel/HM 均超过原版和固定 KC，并给出失效情形（EuroSAT）。

**避免**：不说"首次提出门控"或"全面提升"；kc_rw 是看到 EuroSAT 结果后的事后设计，必须写明；
KC 的基本形式与系数来自 PromptSRC，原创部分只是按样本可信度加权。

- 公式：浅层 `P_v^0 = F_0(P_t^0)`；深层 `P_v^l = F_l(P_t^l), l=1..J-1`，J=9，N_CTX=2。

## 4 静态门控：一个失败但有信息量的尝试（约 1 页，本文特色章节）

4.1 方法：`g_l = 1 + 0.5 tanh(α_l)`，scalar / channel 两种，零初始化。
4.2 **可吸收性命题**：`g ⊙ (W x + b) = (diag(g)W) x + g ⊙ b` → 函数空间不变，只能影响优化轨迹。
    可写成一个 Proposition + 一行证明。
4.3 六数据集结果表（`PROJECT_NOTES.md` 第四节）：scalar/channel 的 ΔHM 正负参半；Aircraft channel −11.89。
4.4 诊断（`DIAGNOSTIC_RESULTS_2026-10-22.md`）：
   - D1 fixed-one 与 none 330 个张量逐位相同 → 不是实现 bug；
   - D2 门控 LR ×0.1 / ×10 都不崩，×1 崩 → 非单调敏感；
   - D3 第 2 epoch 崩溃时门控偏离仅 5.2e-4；崩溃恰好发生在 warmup（1e-5 常数）结束、学习率跳到
     0.0035 的第一个 epoch，此时其余参数梯度范数高达 379 → 指向训练配方本身的脆弱性。
   - 第二阶段补充：Aircraft none/channel 五种子与梯度裁剪结果【填表】。
4.5 小结（过渡到第 5 节）：有效的门控必须 (i) 依赖输入，不能被吸收；(ii) 恒等初始化，保证起点即原模型；
   (iii) 不显著增加计算。

## 5 方法：教师可信度加权的知识一致性（约 1 页）

5.1 固定 KC（PromptSRC 形式）：`L = CE + 25·L1(f_t, f_t^zs) + 10·L1(f_v, f_v^zs) + 1·KL(p‖p^zs)`。
5.2 **可信度加权**：`w_i = p_zs(y_i|x_i)`（冻结 CLIP + 手工模板对训练图像真实类的概率，只用训练标签）。
    图像 L1 与 KL 项逐样本乘 w_i；文本 L1 是类级别项，乘训练中累计均值 w̄。
    直觉：教师在某张图上判断错时，不应把学生往它的特征/分布上拉。
5.3 教师只在训练时使用，推理无额外开销，不进 checkpoint。
5.4 结构图：MaPLe 主干 + 右侧冻结 CLIP 教师分支，w_i 作为三条一致性损失的权重。
