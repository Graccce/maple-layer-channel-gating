# OxfordPets 三种静态门控实验（2026-10-20）

完成 3 模式 × 3 配对种子，共 9 组正式实验。以下为新实现的实测结果，不使用历史 sigmoid 门控日志。

## 协议与来源

固定官方基线 `69bce21ae8eda80ad6187534b2dce09cf6c59e17`；实现参考版本 `58085469070bfaa8fc13e35f414901ef7d55cb11`。新增分析器不改变训练模型。完整源码 SHA-256、环境、数据划分摘要及逐种子数值见 [JSON](results/2026-10-20-oxfordpets.json)。

RTX 3090（24 GiB），Python 3.10.8，torch 2.1.2+cu118，torchvision 0.16.2+cu118，NumPy 1.26.4。ViT-B/16，16 shots，2 context tokens，PROMPT_DEPTH=9（8 个深层投影），fp16；SGD，学习率 0.0035，momentum 0.9，weight decay 0.0005，5 epoch，warmup 1 epoch；训练 batch=4，测试 batch=100，workers=8。三模式使用相同划分和种子 1/2/3。

每组训练后分别在 Base 与 Novel test 上加载同一个 epoch-5 checkpoint。准确率由日志的 correct/total 精确计算（Base 1881，Novel 1788），不使用显示到一位小数的准确率；每个种子先计算 HM=2BN/(B+N)，再报告均值与样本标准差。

## 验证与局限

- 真实 CLIP GPU 单批次：三个模式均通过有限值、反向传播、优化器更新和冻结检查；恒等初始化 logits 与固定官方实现逐元素一致。实测原始 fp16 配方，未验证 CUDA AMP 与完整 fp32 路径。
- 三个一轮 seed-1 数据集 smoke 均完成训练、Base/Novel 评估；不纳入正式结果。
- AutoDL CPU 测试 13 项通过（1.708 秒）；包括严格 checkpoint 家族/形状、真实 Dassl 保存恢复、配置与 runner、精确计数统计及二维小投影的 scalar/channel 折叠测试。
- 9 份 checkpoint 浮点张量全部有限；冻结 CLIP 参数在全部运行间完全相同；源码归档与 manifest 匹配；原始源码及输出 15 个文件的摘要未变。验证布尔记录见 JSON。
- 训练后门控与 1 的最大偏差约 0.00531。CPU float64 下，实际提示投影的门控折叠最大误差 4.1633e-17；这是投影级代数检查，不是折叠后完整 CLIP 的 GPU 精度实验。
- 静态门控可吸收到线性层：W'=diag(g)W，b'=g⊙b，因此不能把额外参数解释为扩大模型函数空间。收益假设主要涉及优化参数化。
- DTD 数据未准备，未运行；固定为 1 的门控、完整模型折叠、冻结投影、门控学习率及正则消融未运行；完整 GPU 中断恢复未验证。
